# Context

Swift Mint already implements CID conversion, ARC-19 and ARC-69 asset creation and mutation, indexer-backed reads,
asset destruction, and IPFS pinning composition across five Swift files. This change documents those existing
contracts and their native or explicitly opt-in integration evidence without changing product code.
